# NOTICE — provenance and rights

Crown Lab is published for reading. **The source code carries no licence: all rights are
reserved**, and there is deliberately no `LICENSE` file, because a licence file would imply a
grant that is not being made. Nothing here may be reused, redistributed or built upon without
written permission.

The assets are a separate matter from the code and from each other, so this file states each
family on its own terms. Where the terms below say *unknown*, that is a statement about the
record, not a claim of permission — missing provenance is recorded rather than inferred.

If you are here to reuse something, the CC0 families are the only ones you may take, and the
MIT one is yours on its own terms.
